# احتيال؟ — ملفات التسليم لـ Claude Code

## وش في المجلد
| الملف | وش فيه |
|---|---|
| `CLAUDE.md` | التعليمات اللي يقرأها Claude Code أول شيء |
| `docs/HANDOFF.md` | الشاشات، والمسارات، والبيانات، والقواعد، وقراراتك كلها |
| `docs/DESIGN.md` | الألوان، والخطوط، والمسافات، والمكوّنات، وقواعد RTL، كلها بالقيم الدقيقة |
| `docs/API.md` | كل الـ routes، وش تستقبل ووش ترجع |
| `docs/AI_SCAN.md` | تعليمات الذكاء الاصطناعي في الكاشف، وطريقة التحقق من رده، والخصوصية |
| `docs/BUILD_PLAN.md` | خطوات البناء بالترتيب، ولكل خطوة طريقة تتأكد فيها إنها اشتغلت |
| `docs/PRD.md` | الـ PRD اللي كتبته أنت |
| `supabase/migrations/0002_english.sql` | أعمدة المحتوى الإنجليزي، ودوال اللعبة صارت ترجع العربي والإنجليزي |
| `supabase/migrations/0001_init.sql` | قاعدة البيانات، والصلاحيات (RLS)، ودوال التصحيح والنقاط والشارات. انجربت كلها |
| `supabase/seed.sql` | ١٦٢ سؤال، و٣ أمثلة للرئيسية، و١٣ شارة، و٨ مقالات |
| `content/*.json` | نفس المحتوى بصيغة JSON، بالعربي والإنجليزي، مع كل نصوص الواجهة (`ui-strings.ar.json` و`ui-strings.en.json`) |
| `mock.json` | بيانات تجريبية للتصميم والاختبار |
| `.env.example` | المفاتيح اللي تحتاجها |

## كيف تبدأ
1. افتح مجلد فاضي، وانسخ فيه هذي الملفات.
2. شغّل Claude Code داخل المجلد، واكتب له:
   > اقرأ CLAUDE.md وابدأ من M0 في docs/BUILD_PLAN.md. لا تنتقل للخطوة اللي بعدها لين تتحقق كل نقاط الفحص.
3. لما يوصل M1: سوّ مشروع في Supabase، وحط المفاتيح في `.env.local`.
4. لما يوصل M6: جيب مفتاح Gemini API من Google AI Studio.
